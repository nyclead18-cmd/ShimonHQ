Outlook on the web

  1. outlook.office.com → Calendar
  2. Add calendar → Subscribe from web
  3. Paste the link, name it Shimon HQ, pick a color → Import

Outlook on the desktop

  1. Calendar → right-click Other calendars → Add calendar → From Internet
  2. Paste the link → OK

iPhone

  1. Settings → Apps → Calendar → Accounts → Add Account → Other
  2. Add Subscribed Calendar → paste the link

Outlook decides how often to refresh a subscribed calendar — usually a few hours, not instant. For something you need in Outlook right now, open the day and use Add to Outlook on the event. Keep this link private: anyone who has it can read your calendar.
